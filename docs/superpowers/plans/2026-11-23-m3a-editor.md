# void.ai Milestone 3a (Editor, Vim, File Tree, Views) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fast code editor in void.ai: rope buffers, tree-sitter highlighting, a clean-room Vim engine (Vim owns Ctrl keys), editor tabs in the dock, a file tree, and a per-tab Disk / chat-view switch.

**Architecture:** Two new UI-agnostic crates — `void-editor` (buffer, undo, syntax, search, file IO) and `void-vim` (the Vim engine over a `VimHost` trait backed by `&ropey::Rope`). The GUI adds an editor tab that draws only visible lines and feeds keys to the engine, a file-tree panel, and editor state that shares one buffer per (path, view). Chat-view saves go through the engine.

**Tech Stack:** ropey 2.0 (beta), tree-sitter 0.27 + grammar crates (rust, typescript/tsx, javascript, json, toml-ng, yaml, md, css, html, bash, python, c, cpp) + their highlight queries, syntect (fallback), regex-cursor, notify 9, trash 5, plus M1–M2's stack.

**Spec:** `docs/superpowers/specs/2026-11-23-m3-editor-design.md`

## Global Constraints

- `void-editor` and `void-vim` don't depend on egui or any UI crate.
- Positions are **char indices into the rope** everywhere (not bytes, not UTF-16); conversions happen at the tree-sitter boundary only.
- Buffers keep LF internally; the file's line ending (LF/CRLF) and whether it ended with a newline are remembered and restored on save.
- Saves use `fsutil::atomic_write` (keeps permissions). Never write a file the user didn't save.
- Vim owns Ctrl keys in the editor: Ctrl+V block, Ctrl+R redo, Ctrl+D/U/F/B/E/Y scroll, Ctrl+O/I jumps, Ctrl+A/X inc/dec, Ctrl+[ = Esc, Ctrl+C cancel. Global: Ctrl+S save, Ctrl+Shift+C/V clipboard, Shift+Shift / Ctrl+Shift+P palette (M3b), Ctrl+Shift+F10 re-run last (M3b).
- Big-file bar: a generated 100 000-line Rust file opens (first frame) in < 200 ms; highlighting may follow within ~1 s (background parse).
- Chat-view saves are refused while that chat's turn is active; otherwise they write the chat's overlay and the agent gets "The user edited ‹path› in your pending changes" at its next turn.
- Commit after each task (`Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`); `moon run :format :lint :test :build` green at every commit.

## Review Focus

1. **Multi-byte text** (é, emoji, CJK, CRLF files): cursor motions, deletes, search and highlighting never split a character or misalign colours. → `buffer_multibyte_edits`, `highlight_spans_align_with_multibyte` (T1, T2).
2. **Undo after a Vim command or insert session** undoes it as one step and restores the cursor. → `undo_groups_insert_session` (T1), `vim_dot_and_undo` (T4).
3. **External change while editing** (agent accept, other editor): no silent overwrite — unsaved buffers get the Reload / Keep mine banner; clean ones reload. → `external_change_reloads_clean_buffer`, `external_change_flags_dirty_buffer` (T7).
4. **Save in chat view during a turn** is refused and leaves the overlay untouched. → `chat_view_save_refused_during_turn` (T8).
5. **Huge or binary files**: a 10 MB file opens without freezing; a binary/non-UTF-8 file opens read-only with a notice. → `loads_large_file_quickly`, `non_utf8_opens_read_only` (T1).

### Task 6: Editor tab in the GUI

**Files:** `apps/void-gui/src/editor/{mod.rs,state.rs,draw.rs,input.rs}`; `layout.rs` (`Tab::Editor { path: PathBuf, view: EditorView }`, `EditorView::{Disk, Chat(ConversationId)}`), `panels/mod.rs`, `app.rs`.

**Behaviour:**
- `EditorStore` (in VoidApp): buffers keyed by `(PathBuf, EditorView)` → `Doc { buffer, syntax, vim: Engine, cursor/selection, scroll, search highlight, parse_in_flight: Option<u64> }`; several tabs on the same key share a Doc.
- Background parse: on open and after edits (debounced ~50 ms), clone the rope and `parse_full` on a thread (`std::thread`), hand the tree back with its version; highlight from the latest tree.
- Drawing: fixed line height (monospace), `ScrollArea::show_rows` over line count; per visible line a `LayoutJob` coloured from `Hl` via the void palette; gutter with absolute/relative numbers; current-line tint; selections (char/line/block); cursor: block in Normal/Visual, bar in Insert; matching bracket outline; soft wrap off (toggle later). Status line inside the tab: mode, `line:col`, language, LF/CRLF, UTF-8 or read-only, pending keys, recording `@a`, messages.
- Input: egui key events → `key_name` → `Engine::key`; text events in insert → `typed`; Ctrl+S save; Ctrl+Shift+C/V clipboard; `:`/`/` prompts drawn as a one-line field at the tab bottom; Vim-off setting → plain editing (arrows, backspace, selection by shift, Ctrl+Z/Y).
- Opening: from file tree (T7), from palette (M3b), from `file:line` links (M3b runner), from Review ("open file"). Tab title: icon by language + file name + `●` when dirty; tooltip full path.
- Closing a dirty tab asks Save / Discard / Cancel.
